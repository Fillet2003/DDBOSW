# Задание с лекции по дисциплине Проектирование и разработка бизнес-ориентированного программного обеспечения

## Задача: разработать модуль учёта времени для системы управления задачами
## Требования:
* Возможность старта и остановки таймера для задачи
* Учёт общего затраченного времени
* Генерация отчётов по времени
* Интеграция с существующей системой задач
